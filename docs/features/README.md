# Feature guides

Reference documentation for what FlowLens does, one file per area. The
[README](../../README.md) is the summary; this is the detail.

| Guide | What's in it |
| --- | --- |

| [Epics](epics.md) | The optional rung between a backlog and its tasks, its provisional estimate, and how it overrides the backlog |
| [Views, search & dashboard](views.md) | Collection filters and sort, paging, full-text search, Markdown descriptions, the cross-project task collection, the dashboard |
| [GitLab CE connection & sync](gitlab-sync.md) | Connecting an instance, linking projects, the initial import, webhooks, sync scope and guarantees, comment sync, TLS, GitLab user identity |
| [API tokens & AI agents](agents.md) | Project-scoped bearer tokens, scopes and the route allowlist, the task context endpoint, the progress convention for agents, the activity log, Agent Kit |
| [Accounts, members & notifications](teams.md) | Changing your password, project membership and roles, invite links, the daily digest webhook |
| [Merge requests](merge-requests.md) | Read-only merge request and pipeline import, task ↔ MR linking, the collection and single views |
| [Metrics](metrics.md) | Delivery metrics, flow metrics and period bucketing, velocity and the points forecast |
